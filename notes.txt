Control Flow Statements 
------------------------
>> Conditional Clause Statement 
>> Looping Statement

Conditional Clause
-------------------
if 
----
syntax:
---------
if cond:
    block of code

True --> execute the block. False --> skip.

elif:
-----
syntax:
----------
elif condition:
    block of code 

True --> execute the block. False --> skip.

else:
---------
Syntax:
---------
else:
    block of code

False --> execute the block. True --> skip.

Nested If 
----------------
if cond1:
    if cond2:
        block of code

Looping Statements
--------------------
while --> condition based loop
for --> sequence based loop

While (no of iteration not known)
--------
>> It is a condition based loop.

Syntax:
----------
while condition:
    block of code

as long as the condition is True it will execute the block of code.

For 
-------
>> It is a sequence based loop.
>> iterates through a sequence.

Syntax:
--------
for var in sequence:
    block of code

Range 
------
range(len) --> range(5) --> [0,1,2,3,4]
range(start, end) --> range(4,14) --> [4,5,6....13]
range(start, end, step) --> range(2,20,2) --> [2,4,6,8....18]

Control Statements of loops 
-----------------------------
break --> stop the loop.
continue --> skip the current iteration.
